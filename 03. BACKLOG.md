## 1. How to Read This Backlog

- **Story** = unit of delivery. Small, demo-able, 0.5–3 days. Tagged with the PRD requirement IDs it satisfies (`FR-*`, `NFR-*`).
- **Epic** = FR section from the PRD (`FR-AUTH` → epic *Authentication*, etc.). Epics organize reporting; they are **not** iteration units.
- **Iteration** = vertical slice. Each ends with something demo-able end-to-end. Iterations 1–5 deliver every **P0** requirement (the MVP launch gate); Iteration 6 is the flex/fast-follow zone.
- **Estimates** are story points (fibonacci), rough calibration placeholders — re-estimate as a team.
- **Cut lines**: if a slice overruns, cut from the bottom of each iteration (stories are ordered by necessity within their slice). Iteration 6 as a whole is deferrable.

### Generic Definition of Done (applies to every story)

- [ ] Code reviewed and merged
- [ ] Server-side rules enforced (never frontend-only hiding) where the story touches documents/access
- [ ] Automated tests for the acceptance criteria
- [ ] No storage URL/key, token, or secret in any client-visible payload or log
- [ ] UI states: loading, empty, error handled
- [ ] Docs/PRD updated if behavior deviates

## 5. Sequencing Notes & Risks

1. **Story 1.4 is the critical path.** The chain middleware + streamed content endpoint is
   touched by nearly every later story. Invest in tests here first (§12.2 automation).
2. **Grant model exists from day 1** (enforcement), grant *management UI* arrives in Iteration 4 —
   interim seeding via script/DB keeps slice 1 honest without building admin screens early.
3. **Open Q1 (email provider)** gates 4.1's delivery mode — default is the copyable-link
   fallback, decided by start of Iteration 4.
4. **Open Q2 (office conversion engine)** gates 6.1 — not needed until then; don't let it
   block the launch gate.
5. **Watermark is deterrence, not protection** (PRD §14 Assumption 5) — keep 2.2 scoped to
   overlay rendering; resist scope creep toward DRM.
6. **Re-estimate 6.1 (8 pts) before pulling it forward** — conversion engines (LibreOffice
   headless etc.) carry deployment surprises; the graceful fallback exists to protect the gate.
